# 天体観測の星図データ

`StargazingSpell` の星座の形を定義する、手管理の client 用 JSON。攻撃範囲やダメージには影響しない。

配置先は `src/main/resources/assets/constellationandspells/stargazing/<ID>.json`。
既存 ID は `lyre`、`crown`、`serpent`、`kite`、`compass`、`phoenix`。

## 書式

```json
{
  "stars": [
    {"x": 0.0, "z": -0.7, "size": 1.4, "brightness": 1.1},
    {"x": -0.6, "z": 0.5},
    {"x": 0.6, "z": 0.5, "size": 0.8}
  ],
  "edges": [[0, 1], [1, 2], [2, 0]]
}
```

### `stars`：星の配列

| フィールド | 必須 | 既定値 | 内容・範囲 |
| --- | --- | --- | --- |
| `x` | 必須 | なし | 星図上の横座標。`-0.9`～`0.9` |
| `z` | 必須 | なし | 星図上の奥行き座標。`-0.9`～`0.9` |
| `size` | 任意 | `1.0` | 星の芯・光輪の大きさの倍率。`0.5`～`2.0` |
| `brightness` | 任意 | `1.0` | 星の明るさの倍率。`0`より大きく`1.5`以下 |

座標はブロック数ではなく、星図中心を `(0, 0)`、四角い攻撃範囲の境界を `±1` とする正規化座標。
実際の配置では半辺長を掛け、詠唱開始時のヨーで星図全体を回転する。`z` の正方向はそのローカルな奥行き方向。
高さは描画側で決まり、データには指定しない。

星は3～64個。数値は有限値を指定する。大きさや明るさを変えると主星を強調できるが、接続線の太さ・明るさは変わらない。

### `edges`：接続線の配列

各要素は、接続する星の **0始まりの配列番号** を2つ並べたもの。
`[0, 2]` は `stars` の1個目と3個目を結ぶ。星の並べ替え・削除時には番号も修正する。

- 線は1～128本。番号は存在する星を指す整数にする。
- 自分自身への線、同じ組み合わせの重複は禁止。`[0, 1]` と `[1, 0]` も重複扱い。
- 接続する2星の正規化座標上の距離は `0.02` 以上。
- すべての星が線をたどってつながる、1つの星座にする。孤立した星や独立した星座の併記は不可。
- 分岐や閉じた輪郭は使用できる。線の交差は許容する。

## 選択と演出

- 1回の展開では、同期された seed と固定の ID リストから1種類を選ぶ。星の位置・接続をランダム生成しない。
- `stars` の順番が星の出現順、`edges` の順番が線を伸ばし始める順番になる。
  線は両端の星の出現状況にも合わせ、最初の20tickで星図を完成させる。
- 色、光輪、脈動、フェードは描画コード側の設定。JSONで変更できるのは形と各星の大きさ・明るさ。

## 編集・追加と反映

既存 ID の JSON はリソースパックでも上書きできる。
新しい種類を追加する場合は、JSONに加えて
[`StargazingChart.IDS`](../src/main/java/jp/aquafactory/constellationandspells/spell/stargazing/StargazingChart.java)
への登録が必要。ファイルを置くだけでは選択対象にならない。

リソースパックの編集後は `F3+T` で再読込できる。
リポジトリの `src/main/resources` を編集した場合は、`./gradlew.bat processResources` で実行用リソースへ反映してから再読込するか、clientを再起動する。
IDリストの変更にはコードの再ビルド・再起動が必要。

不正な定義やファイル不足はログの `Unable to load Stargazing chart` を確認する。
再読込時に直前の有効な定義があれば保持するため、表示が変わらない場合もログを確認する。
初回読込から有効な定義がない ID では、星座部分は描画されない。

書式・接続制約の実装は `StargazingChart`、読込処理は
[`StargazingCharts`](../src/main/java/jp/aquafactory/constellationandspells/spell/stargazing/client/StargazingCharts.java)。
